Educational Reference

What is Packet Sniffing?

Packet sniffing is the practice of intercepting and logging network traffic that passes across a computer network or interface. By tapping into raw socket frames, network analyzers inspect frame headers to evaluate protocol health, troubleshoot routing issues, and uncover unauthorized anomalies.

Why Network Monitoring is Useful

Security Operations Centers (SOCs) rely on 24/7 continuous traffic monitoring to detect cyber threats, lateral movement, port scans, data exfiltration attempts, and distributed denial-of-service (DDoS) spikes. Visibility into IP flow pairs enables rapid incident containment.

TCP Monitoring

Transmission Control Protocol (TCP) is a connection-oriented, reliable transport protocol with a 3-way handshake (SYN, SYN-ACK, ACK). SOC analysts monitor TCP port pairs to detect unusual connections to high-risk ports, port enumeration scans, and persistent reverse shells.

UDP Monitoring

User Datagram Protocol (UDP) is connectionless and low-overhead, commonly carrying DNS queries (port 53), DHCP, VoIP, and video streaming. Because UDP lacks handshakes, monitoring UDP packet rates is vital for identifying DNS amplification attacks and UDP flood vectors.

ICMP Monitoring

Internet Control Message Protocol (ICMP) operates at the network layer for diagnostics (e.g., Echo Request/Reply used by ping, Destination Unreachable, TTL Expired). SOC monitors track ICMP volume to detect Ping Sweeps, ICMP tunneling, and Smurf attack floods.

Importance of Authorized Monitoring

Network packet analysis must strictly be performed in authorized environments with explicit consent. Unsanctioned sniffing violates privacy laws, data protection standards (GDPR, HIPAA), and computer crime statutes. This defensive tool deliberately ignores packet payloads to safeguard privacy.
